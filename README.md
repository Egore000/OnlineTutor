# OnlineTutor LMS Platform

OnlineTutor — это система управления обучением (LMS), разработанная специально для репетиторов. Она предоставляет инструменты для управления расписанием, учениками, заданиями и проверки домашних заданий с помощью ИИ.

## Функционал

- **Управление расписанием**: Легко отслеживайте и организуйте свои занятия.
- **Управление учениками**: Добавляйте, редактируйте и управляйте профилями учеников.
- **Домашние задания**: Назначайте задания ученикам и отслеживайте их выполнение.
- **Проверка заданий с помощью ИИ**: Автоматически оценивайте домашние задания с использованием искусственного интеллекта.

## Установка

1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Egore000/OnlineTutor.git
    ```
2. Перейдите в директорию проекта:
    ```bash
    cd OnlineTutor
    ```
3. Установите зависимости:
    ```bash
    uv install
    ```
4. Запустите приложение:
    ```bash
    uvicorn main:app --reload
    ```

## Настройка базы данных

1. Убедитесь, что Docker установлен и запущен.
2. Запустите контейнер с PostgreSQL:
    ```bash
    docker-compose up -d
    ```
3. Проверьте подключение к базе данных в файле конфигурации.

## Использование

1. Откройте браузер и перейдите по адресу `http://127.0.0.1:8000`.
2. Войдите в систему или создайте учетную запись.
3. Начните управление своими занятиями, учениками и заданиями.

## Используемые технологии

- **FastAPI**: Фреймворк для создания API.
- **PostgreSQL**: База данных для хранения данных.
- **Docker**: Для контейнеризации базы данных.
- **Интеграция ИИ**: Для автоматической проверки домашних заданий.
